🔄 IGST రీఫండ్ పైప్‌లైన్ — ట్రాకర్
1
Shipping Bill లో ఎగుమతి నమోదు
CHA ICEGATE లో Shipping Bill file చేస్తారు. LUT filed అయినందుకు IGST = 0. HS Code, FOB value, Buyer details అన్నీ GSTR-1 తో exactly match అవ్వాలి.
2
GSTR-1 లో Table 6A లో నమోదు
FEED GST team ఆ month GSTR-1 file చేసేటప్పుడు Table 6A లో ఈ ఎగుమతిని నమోదు చేస్తారు. Shipping Bill నంబర్, FOB value, Buyer GSTIN — అన్నీ exact గా match అవ్వాలి.
3
EGM filed తర్వాత ICEGATE ↔ GSTN match
Shipping company EGM file చేసిన తర్వాత ICEGATE మరియు GSTN portal రెండూ data cross-check చేస్తాయి. Shipping Bill ↔ GSTR-1 ↔ GSTR-3B ↔ EGM — అన్నీ match అయితేనే రీఫండ్ process అవుతుంది.
4
90% ముందస్తు రీఫండ్ — 7 రోజుల్లో
అన్నీ match అయిన తర్వాత ICEGATE 90% provisional credit 7 రోజుల్లో FEED AD Bank account కి పంపిస్తుంది. SMS + Email notification వస్తుంది.
5
పూర్తి రీఫండ్ — 60 రోజుల్లో
మొత్తం verification పూర్తి అయిన తర్వాత full refund 60 రోజుల్లో వస్తుంది. ఆలస్యమైతే 6% వడ్డీ వస్తుంది. ICEGATE మొత్తం track చేస్తుంది.
🔗 3-పత్రాల మిళితం తప్పనిసరి — ఏ ఒక్కటి తప్పినా రీఫండ్ ఆగుతుంది
ICEGATE Auto-Match చేసే 4 పత్రాలు
📄 Shipping Bill (ICEGATE) ↔ FOB + HS Code + Buyer
📊 GSTR-1 Table 6A (GSTN) ↔ SB నంబర్ + FOB exact
📋 GSTR-3B Table 3.1(b) ↔ GSTR-1 తో sum match
🚢 EGM (carrier filed) ↔ Vessel + Port + Cargo
✅ అన్నీ Match → స్వయంచాలకంగా రీఫండ్ · ❌ ఒక్కటి miss → రీఫండ్ blocked
⏱️ రీఫండ్ సమయపట్టిక
ముందస్తు 90% provisional credit — EGM తర్వాత 7 రోజుల్లో
పూర్తి 100% full refund — complete verification తర్వాత 60 రోజుల్లో
వడ్డీ 60 రోజులు దాటినా వస్తే వడ్డీ వస్తుంది 6% వార్షిక

⚠️ 3 పొరపాట్లు — తప్పకుండా నివారించండి
❌ పొరపాటు 1: ఏప్రిల్ 1 LUT renewal మర్చిపోవడం
LUT expire అయిన తర్వాత ఎగుమతి చేస్తే — ఆ సంవత్సరం మొత్తం IGST కట్టాలి, రీఫండ్ కోసం 2-6 నెలలు వేచి ఉండాలి. FEED MY EXPORTS లో April 1 countdown reminder ఉంటుంది.
❌ పొరపాటు 2: GSTR-1 Table 6A లో తప్పు data
Shipping Bill FOB value మరియు GSTR-1 Table 6A లో నమోదు చేసిన value exact match అవ్వాలి. ఒక్క రూపాయి తేడా అయినా ICEGATE match చేయలేదు — రీఫండ్ blocked అవుతుంది.
❌ పొరపాటు 3: EGM filing ని confirm చేయకపోవడం
Shipping company EGM file చేయకపోతే IGST రీఫండ్ పూర్తిగా ఆగిపోతుంది. LEO తర్వాత 1-3 రోజుల్లో EGM ICEGATE లో కనిపించాలి. కనిపించకపోతే వెంటనే Maersk కి escalate చేయండి.
