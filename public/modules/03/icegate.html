📚 ICEGATE అంటే ఏమిటి?
CBIC · Indian Customs Electronic Gateway · India's customs nervous system
ICEGATE (Indian Customs Electronic Gateway) భారతదేశ కస్టమ్స్ శాఖకు చెందిన ప్రధాన డిజిటల్ మౌలిక వ్యవస్థ (Customs Digital Backbone).
ఇది ఆర్థిక మంత్రిత్వ శాఖ ఆధ్వర్యంలోని CBIC (Central Board of Indirect Taxes and Customs) నిర్వహిస్తుంది. దేశవ్యాప్తంగా 250+ కస్టమ్స్ కేంద్రాలను అనుసంధానించి, అంతర్జాతీయ వాణిజ్యానికి సంబంధించిన సుమారు 98% దిగుమతి–ఎగుమతి పత్రాల ప్రాసెసింగ్ నిర్వహిస్తుంది.

ప్రధాన సేవలు: IEC, AD Code, GSTIN, DSC అనుసంధానం; e-Sanchit ద్వారా పత్రాల అప్లోడ్; Shipping Bill దాఖలు; LEO, EGM, RoDTEP లెడ్జర్, IGST రీఫండ్ వంటి ఎగుమతి–కస్టమ్స్ ప్రక్రియలు.

📋 7-Step Registration Workflow
icegate.gov.in · CBIC review 3-4 working days
Importer/Exporter Registration · ICEGATE 2.0
~3-4 days
1
Visit Portal
Open www.icegate.gov.in in Chrome/Edge · click "Sign Up / Register" on homepage.
2
User Type Selection
Select "Importer or Exporter" · Enter IEC + PAN + GSTIN · System validates real-time against DGFT + GST databases. Validation FAIL = IEC-PAN-GSTIN inconsistency → resolve at source first.
3
Profile Details
Authorised Signatory Name (must match DSC subject exactly) · Designation · Mobile (OTP) · Email (OTP) · Address (must match IEC).
4
Password + 2FA Setup
User ID (typically IEC-based) · strong password (8+ chars, upper+lower+number+special) · security questions · 2FA: mobile OTP + email OTP.
5
DSC Linking
Insert USB token with Class 3 DSC · emSigner application detects DSC · sign registration with DSC. DSC subject name MUST match authorised signatory name exactly.
6
e-Sanchit Document Upload
PDFs upload: Auth Letter, PAN, IEC, GST, Cancelled Cheque, Address proof. Each upload generates 16-digit IRN (Image Reference Number) · save all IRN numbers for subsequent steps.
7
Submission + CBIC Approval
Submit + OTP verification (mobile + email) · CBIC review 3-4 working days · Approval notification on email + portal · Login activated post-approval.
