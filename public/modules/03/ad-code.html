📚 AD Code అంటే ఏమిటి?
Bhagam 7 (Banking) · RBI FEMA framework
Exporter's AD Bank కి RBI ఇచ్చిన unique 14-digit code · ICEGATE shipping bill కి తప్పనిసరి identifier.
AD Code = Authorised Dealer Code. విదేశీ మారక ద్రవ్య (foreign exchange) లావాదేవీలు handle చేయడానికి RBI Authorised Dealer Category-I banks కి అధికారం ఇస్తుంది. ప్రతి AD Bank కి RBI ఇచ్చిన unique 14-digit AD Code ఉంటుంది. మీ export business కోసం bank మీ current account కి ఈ AD Code link చేస్తుంది. ICEGATE లో AD Code register చేయకపోతే — shipping bill submit అవ్వదు, FIRC రాదు, RBI EDPMS export reporting జరగదు. ఇది banking + customs + RBI ఇంటర్‌సెక్షన్‌లో critical missing piece. CBIC Advisory No. 10/2022 (14 June 2022) ప్రకారం ఇప్పుడు ఒక్క customs location లో AD Code register చేస్తే చాలు — అది దేశంలో అన్ని ICEGATE ports కి automatically వర్తిస్తుంది, పాత "ప్రతి port కి వేరే registration" system తీసేశారు.

1
AD Bank Branch Visit
మీ AD Bank శాఖకు వెళ్ళండి (FEED case: SBI Anantapur). "Export Business తెరవాలి" అని చెప్పండి. Bank officer current account ki AD Code link request submit చేస్తారు.
2
AD Code Certificate Issue
Bank verification పూర్తి అయ్యాక AD Code certificate issue చేస్తారు (PDF + physical). Document లో: bank name, branch IFSC, 14-digit AD Code, current account number, account holder details.
3
ICEGATE Registration (One-Time)
icegate.gov.in → exporter login → AD Code registration → ఒక్క port (e.g. KPCT) లో register చేస్తే చాలు. CBIC Advisory 10/2022 ప్రకారం ఇది Vizag, Chennai, Mundra సహా అన్ని ports కి automatically apply అవుతుంది. 24-48 hr activation. Duty Drawback/IGST refund కోసం bank IFSC మాత్రం port-wise verify చేయాల్సి రావొచ్చు.
