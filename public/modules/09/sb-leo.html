పూర్తి ప్రయాణం — ఒక్క చూపులో
కంటైనర్ పోర్ట్ గేట్‌లోకి వచ్చినప్పటి నుంచి నౌక గమ్యస్థాన పోర్ట్‌కు చేరే వరకు జరిగే ప్రతి దశ, అందులో పాల్గొనేవారు, అవసరమైన పత్రాలు ఇక్కడ వివరించబడ్డాయి.
Gate-In ✅ → Customs 🔍 → LEO ✅ → Loaded 🚢 → Sailing 🌊 → Destination ⚓ → Delivered 📦
🟢
STEP 1 — పోర్ట్ Gate-In
🚛 కంటైనర్ పోర్ట్‌లోకి ప్రవేశం
ఎగుమతి కంటైనర్‌ను ట్రక్ ద్వారా పోర్ట్ టెర్మినల్‌కు తీసుకువస్తారు.
ఇక్కడ ఏమి జరుగుతుంది?
  • కంటైనర్ పోర్ట్ గేట్ వద్ద నమోదు అవుతుంది
  • కంటైనర్ నంబర్, ట్రక్ వివరాలు, సీల్ వివరాలు నమోదు చేస్తారు
  • టెర్మినల్ కంటైనర్‌ను Yardలోకి తీసుకుంటుంది
ఎవరు పాల్గొంటారు?
👤 Exporter / FEED 🚛 Transporter 🏗️ Port Terminal
📄 సాధారణంగా అవసరమయ్యేవి
Shipping Bill Delivery Order (DO) — వర్తిస్తే Invoice Packing List Container & Truck details
🟢
STEP 2 — Terminal Check
🏗️ కంటైనర్ టెర్మినల్‌లో తనిఖీ
కంటైనర్ Yardలోకి వచ్చిన తర్వాత టెర్మినల్ దాని వివరాలను తనిఖీ చేసి, నిర్దేశించిన స్థలంలో ఉంచుతుంది.
ఇక్కడ ఏమి జరుగుతుంది?
  • Container number verification
  • Seal verification
  • Weight / VGM verification
  • Booking & vessel details matching
  • Yard placement
ఎవరు పాల్గొంటారు?
🏗️ Terminal 🚢 Shipping Line
📄 సాధారణంగా అవసరమయ్యేవి
Booking confirmation VGM Container details Shipping instructions — వర్తిస్తే
🟢
STEP 3 — Customs Processing
🛃 కస్టమ్స్ క్లియరెన్స్
కస్టమ్స్ మీ Shipping Bill ఆధారంగా ఎగుమతి సరుకును ప్రాసెస్ చేస్తుంది.
ఇక్కడ ఏమి జరుగుతుంది?
  • Shipping Bill processing
  • Risk assessment
  • అవసరమైతే document / physical examination
  • Customs clearance కోసం అవసరమైన తనిఖీలు
ఎవరు పాల్గొంటారు?
👨‍💼 CHA / Customs Broker 🛃 Customs
📄 సాధారణంగా అవసరమయ్యేవి
Shipping Bill Commercial Invoice Packing List అవసరమైన supporting certificates
⚠️ గమనిక: తనిఖీలు, అదనపు పత్రాలు సరుకు మరియు గమ్యదేశాన్ని బట్టి మారవచ్చు.
🟢
STEP 4 — Product / Regulatory Inspection
🔍 సరుకు ఆధారంగా అవసరమైన తనిఖీలు
కొన్ని వ్యవసాయ మరియు ఆహార ఉత్పత్తులకు అదనపు తనిఖీలు లేదా సర్టిఫికెట్లు అవసరం కావచ్చు.
ఉదాహరణలు
  • Phytosanitary Certificate
  • Fumigation Certificate
  • Laboratory / Quality Test Certificate
  • ఇతర destination-specific certificates
ఎవరు పాల్గొంటారు?
🌱 DPPQS / సంబంధిత అధికారి 🔬 Approved Laboratory / Agency — అవసరమైతే 👨‍💼 CHA / Exporter
⚠️ ప్రతి shipmentకు అన్ని certificates అవసరం ఉండవు. ఉత్పత్తి + గమ్యదేశం + buyer requirements ఆధారంగా అవసరమైనవి మారుతాయి.
🟢
STEP 5 — Container Sealing
🔒 కంటైనర్ సీల్
అవసరమైన తనిఖీలు పూర్తయిన తర్వాత కంటైనర్ సీల్ వివరాలు నమోదు/ధృవీకరించబడతాయి.
ఇక్కడ ఏమి జరుగుతుంది?
  • Seal number నమోదు
  • Container details update
  • Inspection / clearance records update
ఎవరు పాల్గొంటారు?
🛃 Customs / సంబంధిత అధికారి 🏗️ Terminal 👨‍💼 Exporter / CHA
📄 ముఖ్యమైన సమాచారం
Container Number Seal Number Inspection / clearance details
✅
STEP 6 — LEO (Let Export Order)
✅ ఇది చాలా ముఖ్యమైన దశ
కస్టమ్స్ అవసరమైన ప్రక్రియలు పూర్తి చేసిన తర్వాత LEO (Let Export Order) ఇస్తుంది.
LEO అంటే?
సరుకును ఎగుమతి చేయడానికి Customs అనుమతి ఇచ్చింది అని అర్థం.
ఎవరు పాల్గొంటారు?
🛃 Customs 👨‍💼 CHA
❌ LEO రాకముందు: Export clearance పూర్తయినట్లు భావించకూడదు.
➡️ LEO తర్వాత: కంటైనర్ vessel loading కోసం ముందుకు వెళ్తుంది.
🟢
STEP 7 — Yard నుంచి Vesselకు
🚢 కంటైనర్ నౌకలో ఎక్కే దశ
LEO మరియు ఇతర loading requirements పూర్తయిన తర్వాత కంటైనర్‌ను Yard నుంచి vesselకు తరలిస్తారు.
ఇక్కడ ఏమి జరుగుతుంది?
  • Vessel plan ప్రకారం container movement
  • Container loading
  • Shipping line records update
ఎవరు పాల్గొంటారు?
🏗️ Terminal 🚢 Shipping Line
📄 ముఖ్యమైనవి
LEO VGM Vessel / Booking details
🟢
STEP 8 — Vessel Sails
🌊 నౌక పోర్ట్ నుంచి బయలుదేరుతుంది
కంటైనర్ నౌకలో లోడ్ అయిన తర్వాత vessel గమ్యస్థానం వైపు ప్రయాణం ప్రారంభిస్తుంది.
ఇక్కడ ఏమి జరుగుతుంది?
  • Vessel departure
  • Container tracking update
  • Shipping line shipment status updates
ఎవరు పాల్గొంటారు?
🚢 Shipping Line / Vessel Operator 🏗️ Port / Terminal
📄 ముఖ్యమైన పత్రాలు
Bill of Lading Shipping records EGM — applicable shipping records
🟢
STEP 9 — Destination Port
🌍 గమ్యస్థాన పోర్ట్‌కు కంటైనర్ చేరుతుంది
నౌక buyer దేశంలోని destination portకు చేరిన తర్వాత import-side ప్రక్రియ ప్రారంభమవుతుంది.
ఇక్కడ ఏమి జరుగుతుంది?
  • Vessel arrival
  • Container discharge
  • Destination customs process
  • Import clearance
  • Cargo release
ఎవరు పాల్గొంటారు?
🛃 Destination Customs 🚢 Shipping Line 👤 Buyer / Consignee 👨‍💼 Destination CHA / Agent
📄 సాధారణంగా అవసరమయ్యేవి
Bill of Lading Commercial Invoice Packing List Certificate of Origin Destination-specific certificates
⚠️ Destination requirements buyer దేశం మరియు సరుకు ఆధారంగా మారుతాయి.
⚠️
DELAY అయితే ఏమవుతుంది? — Demurrage & Detention
ఎగుమతిలో Free Time అనే పరిమితి ఉంటుంది. అది దాటితే అదనపు charges రావచ్చు.
🔴
Demurrage
కంటైనర్ పోర్ట్/టెర్మినల్‌లో ఎక్కువకాలం ఉండిపోతే వచ్చే charge.
🟡
Detention
Shipping Line containerను port బయట ఉపయోగించిన తర్వాత నిర్ణయించిన free timeలో తిరిగి ఇవ్వకపోతే వచ్చే charge.
సులభంగా గుర్తుంచుకోండి:
Demurrage = Port లో ఆలస్యం
Detention = Container బయట ఉండి return చేయడంలో ఆలస్యం
⏰ Free Time తప్పక తెలుసుకోవాలి — మీ shipment కోసం:
  • ఎంత Free Time ఉంది?
  • Free Time ఎప్పటి నుంచి లెక్కిస్తారు?
  • అది ఎప్పుడు ముగుస్తుంది?
  • Demurrage / Detention tariff ఎంత?
👉 ఇవి Shipping Line / Terminal నుంచి ముందే confirm చేయాలి.
⚠️ Vessel Cut-off మిస్ అయితే?
ఇది Demurrage/Detentionతో వేరే విషయం.

Vessel Cut-off మిస్ → planned vesselలో container load కాకపోవచ్చు → rollover / rebooking → అదనపు ఖర్చు లేదా ఆలస్యం రావచ్చు.

Free Time మిస్ → Demurrage / Detention charges రావచ్చు.

SAGAR SETU + ONOP — Digital Process
📲 Digital Process వల్ల Cargo Flow Smooth
ఎగుమతి ప్రక్రియలో అనేక parties, documents మరియు port-related activities ఉంటాయి. SAGAR SETU + ONOP లక్ష్యం: port-related processesను మరింత digital, standardized మరియు coordinated గా చేయడం.
📲
SAGAR SETU: Digital / single-window facilitation ద్వారా port-related services మరియు documentationను సులభతరం చేయడంలో సహాయపడుతుంది.
🔄
ONOP — One Nation One Port: Port-related processesలో standardization మరియు integrationను ప్రోత్సహిస్తుంది.

❓ తరచు అడిగే ప్రశ్నలు
ప్ర: ICEGATE లో SB status రైతు స్వయంగా చూడవచ్చా?
జ: అవును — enquiry.icegate.gov.in లో login అవసరం లేకుండా public access ఉంది. Port code INKRI1 + SB నంబర్ 8274651 + తేదీ enter చేస్తే real-time 8-stage status కనిపిస్తుంది. రైతు మొబైల్ browser లో check చేయవచ్చు. FEED platform లో కూడా status auto-sync అవుతుంది.
ప్ర: LEO వచ్చిన తర్వాత SB లో ఏదైనా మారుస్తామా?
జ: LEO తర్వాత major changes అసాధ్యం — scheme code, HS code, RoDTEP claim మార్చడం సాధ్యం కాదు. అందుకే SB file చేయడానికి ముందే FEED checklist పూర్తి confirm. LEO కి ముందు consignee name వంటి minor corrections మాత్రమే possible.
