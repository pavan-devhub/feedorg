Shipping Bill లో RoDTEP=Y declare చేయాలి — LEO తర్వాత మారదు
Shipping Bill file చేసేటప్పుడు RoDTEP "Y" (Yes) select చేయాలి. ఒకవేళ మర్చిపోతే — LEO వచ్చిన తర్వాత మార్చలేరు. రామయ్య గారికి Banana FOB ₹34,56,000 × 0.5% = ₹17,280 శాశ్వతంగా పోతుంది. FEED platform Shipping Bill form లో ఇది auto-select చేస్తుంది.
AP Chapter 1-24 RoDTEP — February 25, 2026 నుండి పునరుద్ధరించబడింది. Banana (HS 0803 90 10): ≈ 0.5% FOB · ₹17,280 ఒక consignment లో. Chilli (HS 0904 21 00): ≈ 2.0–3.5% FOB. Drawback కూడా declare చేయాలి.
📖 షిప్పింగ్ బిల్ అంటే ఏమిటి? — సరళంగా అర్థం చేసుకోండి
1
ఎగుమతి అనుమతి అర్జీ — "మేము ఈ సరుకు India నుండి UAE కి export చేయాలనుకుంటున్నాం — అనుమతించండి" అని customs కి digital form లో అడగడం. ఇది India లో అన్ని exports కి mandatory.
2
7-digit unique number — Shipping Bill submit అయిన తర్వాత 7-digit Shipping Bill Number వస్తుంది (Port-wise unique). ఈ నంబర్ RoDTEP, EDPMS, FIRC, eBRC అన్నిటికీ ఆధారం.
3
RMS Channel నిర్ణయం — Submit చేసిన తర్వాత ICEGATE Risk Management System (RMS) Green / Orange / Red channel నిర్ణయిస్తుంది. Green = తనిఖీ లేకుండా నేరుగా LEO. FEED records clean = Green channel.
4
LEO వచ్చేదాకా వేచి ఉండాలి — Shipping Bill filed తర్వాత customs LEO (Let Export Order) ఇస్తే — vessel లో load చేయవచ్చు. LEO లేకుంటే container port gate నుండి వెళ్ళలేదు.

🪜 Shipping Bill filing — కీలక దశలు
1
అన్ని 9 IRNలు సిద్ధంగా ఉండాలి
e-Sanchit (S-27) లో అన్ని పత్రాలు upload అయి IRN వచ్చిన తర్వాతే Shipping Bill file చేయవచ్చు. Phyto IRN-4 వచ్చిన తర్వాతే — stuffing రోజు.
9 IRNలు = Shipping Bill ready
2
CHA ICEGATE లో data enter + DSC sign
FEED CHA ICEGATE లో login చేసి HS Code, FOB, IRN links, RoDTEP=Y, Drawback=Y enter చేసి Class 3 DSC తో sign చేసి submit చేస్తాడు.
RoDTEP=Y మర్చిపోవద్దు — auto-check FEED
3
7-digit SB Number వస్తుంది — track చేయండి
Submit అయిన వెంటనే 7-digit Shipping Bill Number generate అవుతుంది. FEED platform దీన్ని auto-save చేసి EDPMS, RoDTEP, eBRC chain లో link చేస్తుంది.
SB Number = అన్నిటికీ reference
4
RMS Green Channel → LEO వేచి ఉండటం
FEED clean records వల్ల Green Channel అవుతుంది — అదే రోజు LEO వచ్చే అవకాశం ఎక్కువ. enquiry.icegate.gov.in లో status track చేయవచ్చు.
enquiry.icegate.gov.in · public tracking
5
LEO వస్తే — container vessel లో load చేయవచ్చు
LEO Granted అయిన తర్వాత KPCT port gate నుండి container vessel దగ్గరకు వెళ్ళుతుంది. Maersk vessel లో load అవుతుంది. S-29 LEO tracker లో confirm చేయండి.
LEO = Legal Export Permission

🤖 FEED Platform ఎలా సహాయం చేస్తుంది?
⚡
స్వయంచాలక Shipping Bill తయారీ
FEED platform అన్ని data Invoice నుండి auto-fill చేస్తుంది. RoDTEP=Y auto-select. IRN links auto-attach. CHA కి ready format పంపిస్తుంది.
1
LEO SMS Alert — LEO "Granted" అయిన వెంటనే FEED platform రామయ్య గారికి + FCDA కి Telugu లో WhatsApp + SMS పంపిస్తుంది. "మీ సరుకుకు export అనుమతి వచ్చింది!"
2
EDPMS auto-link — SB Number వెంటనే AD Bank కి share చేసి EDPMS link చేస్తుంది. 15-month FEMA timer auto-start అవుతుంది.
3
Query auto-respond — Orange/Red channel వస్తే customs query వస్తుంది. FEED platform query Telugu లో translate చేసి respond చేసే help ఇస్తుంది.
⚠️ తరచుగా జరిగే తప్పులు — జాగ్రత్తగా ఉండండి
తప్పు #1 — ₹17,280 శాశ్వతంగా పోయింది
RoDTEP declare చేయకపోవడం — SB form లో RoDTEP "N" select చేస్తే — LEO తర్వాత మార్చడం impossible. ఆ shipment కి RoDTEP శాశ్వతంగా పోతుంది. FEED: auto-Y — కానీ CHA confirm చేయాలి.
తప్పు #2 — Customs query · vessel miss
HS Code తప్పుగా enter చేయడం — 0803 90 10 బదులు 0803 90 90 enter చేస్తే — customs query వస్తుంది. Query reply చేయడానికి 2–3 రోజులు పోతుంది. Vessel sailing miss అవుతుంది. LC expiry risk వస్తుంది.
తప్పు #3 — Goods Registration miss
SB file చేసి cargo port కి పంపకపోవడం — Shipping Bill file చేసినప్పటికీ, cargo KPCT కి physically arrive అయి Goods Registration complete అయితేనే customs process చేయగలదు. SB + Cargo arrival = రెండూ కావాలి.
