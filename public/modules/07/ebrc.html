🪜 eBRC ఎలా generate చేయాలి? — దశలు
1
Buyer payment → SBI లో FIRC
UAE buyer $41,638 payment పంపిస్తే — SBI Anantapur లో receive అవుతుంది. Bank SWIFT MT 103 + FIRC issue. Simultaneously EDPMS 'Open' → 'Closed' అవుతుంది.
FIRC = payment proof ✓
2
Bank IRM DGFT portal కి upload చేస్తుంది
AD Bank SBI Anantapur payment receive అయిన 1-2 రోజులలో IRM (Inward Remittance Message) DGFT portal లో upload చేస్తుంది. FEED CFO DGFT portal లో IRM visible అవుతుంది.
Auto — bank uploads IRM
3
DGFT Portal → eBRC Module → IRM match
dgft.gov.in → Dashboard → Exporters → eBRC → IRM visible. FEED CFO IRM ని Shipping Bill 8274651 తో match చేస్తుంది. పొరపాటు లేకపోతే verify చేస్తుంది.
IRM → SB match mandatory
4
Self-Certification → eBRC XML generate
"This linkage is correct" అని FEED CFO self-certify చేస్తే — DGFT system eBRC XML auto-generate చేస్తుంది. Unique eBRC reference number వస్తుంది.
eBRC Generated ✓
5
eBRC download → RoDTEP + Drawback discharge
eBRC generated తర్వాత RoDTEP scrip release + Drawback credit + EPCG EO discharge అన్నీ process అవుతాయి. EDPMS closure confirmed.
₹17,280 + Drawback unlocked 🎉
6
FEED Stage 7 Flow 3 → 4 ERP entries auto-post
FIRC + eBRC confirmed తర్వాత FEED platform 4 ERP entries auto-post: AC-14 Bank + AC-31 Forex + AC-12 RoDTEP JV + AC-12 Drawback JV. 93% → రైతు PACS account.
₹32,14,080 → PACS ✓
