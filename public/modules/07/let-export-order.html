📖 LEO అంటే ఏమిటి? — సరళంగా అర్థం చేసుకోండి
1
"దేశం వదిలే అనుమతి" — Let Export Order = కస్టమ్స్ అధికారి "ఈ సరుకు India వదిలి వెళ్ళవచ్చు" అని digitally sign చేసే document. ఇది ICEGATE లో auto-generate అవుతుంది.
2
అన్నిటికీ gate — LEO లేకుంటే: container port లో stuck అవుతుంది. Vessel miss అవుతుంది. LC expiry వస్తుంది. Payment ఆగుతుంది. LEO = అన్ని తదుపరి దశలకు తాళం చెవి.
3
Green Channel = అదే రోజు LEO — FEED records clean వల్ల RMS Green Channel వస్తుంది. Green channel లో customs officer manual review చేయడు. ICEGATE system automatically LEO issue చేస్తుంది.
4
Post-LEO = locked — LEO వచ్చిన తర్వాత RoDTEP scheme code, HS Code మార్చలేరు. Pre-LEO window లో మాత్రమే corrections సాధ్యం. FEED platform pre-LEO all checks auto-complete చేస్తుంది.

📦 EGM — Export General Manifest అంటే ఏమిటి?

EGM = Maersk file చేస్తుంది — FEED కాదు
EGM అంటే "vessel లో load అయిన అన్ని cargo manifest." Shipping Line (Maersk) ICEGATE లో file చేయాలి — exporter కాదు. Departure తర్వాత 1–7 రోజులలో.

3
EGM + FIRC chain track — EGM status ICEGATE లో check చేసి FEED platform RoDTEP scrip ready అయిన తర్వాత auto-generate చేస్తుంది. FIRC వచ్చిన తర్వాత ₹32.14L PACS account కి auto-distribute.
⚠️ తరచుగా జరిగే తప్పులు — జాగ్రత్తగా ఉండండి
తప్పు #1 — Vessel miss అయింది
Vessel cut-off కి ముందు LEO రాకపోవడం — Vessel sailing cut-off deadline ఉంటుంది. LEO delay వల్ల cut-off miss అయితే — next vessel వేచి ఉండాలి. LC expiry risk వస్తుంది. Banana 7–8 రోజుల voyage — LC కి కనీసం 14 రోజుల buffer ఉండాలి.
తప్పు #2 — ₹17,280 + IGST blocked
EGM tracking చేయకపోవడం — Maersk EGM file చేశాడో లేదో FEED CHA check చేయాలి. EGM delayed అయితే RoDTEP scrip + IGST refund రెండూ blocked. Departure తర్వాత 7 రోజులలో EGM confirm అవ్వాలి.
తప్పు #3 — Temperature breach · Insurance claim
Reefer temperature monitoring ignore చేయడం — Voyage లో temperature 15°C దాటినా లేదా 12°C కి తగ్గినా — వెంటనే alert చేయకపోతే Jebel Ali లో buyer reject చేయవచ్చు. FEED platform alert 30 minutes లో respond చేయాలి.
