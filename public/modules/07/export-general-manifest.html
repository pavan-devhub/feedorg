📖 EGM అంటే ఏమిటి? — సరళంగా అర్థం చేసుకోండి
1
నౌక cargo జాబితా — ఒక vessel లో India నుండి వెళ్ళే అన్ని consignments జాబితా. "రామయ్య గారి container MRKU3456789 ఈ vessel లో వెళ్ళింది" అని అధికారిక నమోదు.
2
Maersk file చేస్తుంది — FEED కాదు — EGM filing responsibility carrier (Maersk) ది. FEED తరపున ICEGATE లో file చేయలేరు. Vessel departure తర్వాత 1–7 రోజులలో Maersk ICEGATE లో file చేస్తుంది.
3
అన్ని benefits ఇక్కడ నుండి — EGM filed అయిన తర్వాతే — customs RoDTEP scroll generate చేస్తుంది. IGST refund pipeline opens. Duty Drawback eligible అవుతుంది. eBRC process అవుతుంది.
4
FEED CHA follow-up తప్పనిసరి — Maersk EGM file చేశారో లేదో FEED CHA track చేయాలి. 7 రోజులు దాటినా EGM రాకపోతే — Maersk ని escalate చేయాలి. FEED platform auto-alert చేస్తుంది.
🔓 EGM filed → అన్ని benefits unlock — వివరంగా
🌿
RoDTEP Scrip — ₹17,280 (S-70 తదుపరి)
EGM filed తర్వాత customs 15–30 రోజులలో RoDTEP scroll generate చేస్తుంది. FEED ICEGATE e-Scrip module లో scrip generate చేయాలి. Banana 0.5% × ₹34,56,000 = ₹17,280. AP Chapter 1-24 restored Feb 25, 2026.
₹17,280 scrip · generate immediately
💰
IGST Refund — LUT ఆధారంగా
FEED LUT (Letter of Undertaking) ఉంది కాబట్టి IGST collect చేయలేదు. EGM + GSTR-1 Table 6A match అయితే IGST refund auto-process. 3–4 వారాలలో FEED AD Bank account కి credit.
LUT basis · auto-credit
🏦
Duty Drawback — input taxes రీఫండ్ (S-71 తదుపరి)
Packing materials, cold chain equipment, other inputs కి paid customs/taxes drawback గా వస్తుంది. EGM filed తర్వాత 72 గంటలలో (AEO T2 users కి) లేదా 7–15 రోజులలో.
SB filing లో declared · auto-credit
📄
eBRC + EDPMS Closure — FIRC chain
EGM closure → EDPMS entry 'EGM Filed' status → FIRC arrived తర్వాత EDPMS 'Closed' అవుతుంది → eBRC auto-generate → RoDTEP prerequisite complete. 15-month FEMA timer counts from SB date.
FIRC → eBRC → complete

⚠️ EGM delayed అయితే — escalation protocol
⚡
7 రోజులు దాటినా EGM రాకపోతే — వెంటనే చర్య తీసుకోండి
దశ 1: FEED CHA Maersk agent ని directly contact చేయాలి. Vessel voyage number + SB number ఇచ్చి EGM status అడగాలి.
దశ 2: Maersk respond చేయకపోతే — ICEGATE grievance portal లో lodge చేయవచ్చు.
దశ 3: Persistent delay → customs commissioner level escalation.
EGM delay = RoDTEP + IGST + Drawback అన్నీ delayed. ₹17,280+ at risk.
🤖 FEED Platform ఎలా సహాయం చేస్తుంది?
⚡
EGM Auto-Track + Benefits Unlock
FEED platform ICEGATE లో daily EGM status check చేస్తుంది. EGM filed అయిన తర్వాత auto-alert + RoDTEP scrip generation reminder + IGST refund pipeline alert — అన్నీ Telugu లో.
1
EGM alert SMS — "మీ EGM filed అయింది! RoDTEP scrip generate చేయండి" — ICEGATE లో EGM confirm అయిన వెంటనే FEED platform Telugu SMS పంపిస్తుంది.
2
RoDTEP scrip auto-generate — Scroll visible అయిన వెంటనే FEED platform ICEGATE e-Scrip module లో auto-generate చేస్తుంది. Delay = budget compression risk.
3
7-day EGM follow-up — Departure తర్వాత 7 రోజులు దాటినా EGM రాకపోతే FEED platform CHA కి auto-escalation reminder పంపిస్తుంది.
⚠️ తరచుగా జరిగే తప్పులు — జాగ్రత్తగా ఉండండి
తప్పు #1 — ₹17,280 delay అయింది
EGM tracking చేయకపోవడం — Maersk EGM file చేశారో లేదో check చేయకపోతే — RoDTEP scroll delayed అవుతుంది. Budget compression risk వల్ల scrip amount తగ్గవచ్చు. EGM confirmed తర్వాత వెంటనే scrip generate చేయాలి.
తప్పు #2 — IGST refund blocked
EGM mismatch — container number తప్పు — Maersk EGM లో container MRKU3456789 తప్పుగా రాస్తే — ICES Shipping Bill తో match చేయలేదు. IGST refund + Drawback రెండూ blocked. CHA Maersk EGM draft confirm చేయాలి.
తప్పు #3 — FEMA compliance miss
EDPMS closure track చేయకపోవడం — EGM + FIRC రెండూ అయిన తర్వాత EDPMS 'Closed' అవాలి. 15 months (SB date నుండి) లోపు FIRC రాకపోతే RBI FEMA compliance violation. FEED platform 15-month countdown track చేస్తుంది.
